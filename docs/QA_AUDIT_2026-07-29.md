## Automation defects found and corrected

These were false failures in the QA suite rather than application bugs:

- Fixed action coordinates broke when newer records changed table row order.
- Report, account, leak type, pressure, visibility, and covering labels shared
  IDs with their controls; the controls require `index: 1`.
- `Blow-Off` matched a background dashboard value behind the modal; the
  dropdown option requires the second exact match.
- Customer-report search state leaked into the Dispatched status view.
- Status-option assertions kept the temporary dropdown open too long.
- Dashboard report reference text is not a supported details action; Operations
  is the supported details route.
- Dashboard Location contains the selected address, not the landmark.
