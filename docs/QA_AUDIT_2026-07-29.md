# Leak Alert QA Audit — July 29, 2026

Environment: DCWD development portal  
Automation: Maestro managed Chromium  
Test identity: Administrator QA account  
Scope: Critical, Reports, Operations, Maintenance, Administration, navigation,
negative paths, persistence, controlled record creation, and audit history

## Executive result

Release recommendation: **Not ready for production**

The critical smoke pack passed, but testing confirmed data-integrity, duplicate
submission, and audit-trail defects. Several automation flows also used
coordinate selectors that generated false failures when table row positions
changed. Those selectors were stabilized during this audit.

Severity: Critical  
Status: Confirmed  
Affected reference: `2026072C26`

Steps to reproduce:

1. Create a leak report.
2. Select Leak Type `Blow-Off`.
3. Select Leak Pressure `Low`.

Automated flow: `flows/operations/02-open-report-action.yaml`

## Automation defects found and corrected

These were false failures in the QA suite rather than application bugs:

- Fixed action coordinates broke when newer records changed table row order.
- Report, account, leak type, pressure, visibility, and covering labels shared
  IDs with their controls; the controls require `index: 1`.
- `Blow-Off` matched a background dashboard value behind the modal; the
  dropdown option requires the second exact match.
- Customer-report search state leaked into the Dispatched status view.
- Status-option assertions kept the temporary dropdown open too long.
- Dashboard report reference text is not a supported details action; Operations
  is the supported details route.
- Dashboard Location contains the selected address, not the landmark.

## Critical coverage still blocked

- Repair scheduling, field repair, evidence upload, turnover, and closure need a
  dedicated repair-crew QA account.
- Role-by-role authorization needs separate administrator, dispatcher, crew,
  restricted, and read-only identities.
- API/database verification is needed to determine whether the pressure defect
  is stored incorrectly or only rendered incorrectly.
- Security, accessibility, cross-browser, performance, concurrency, and
  network-recovery testing have not yet been executed.
